# 心动指数 · 你对 TA 的心动指数

**在线测试：<https://ljr556.github.io/heart-index/>**

30 道题，测出你对 TA 的真实在意程度。测完给一份**五维报告 + 场景专属解读 + 可保存的分享卡片**。

打开就能测，不需要授权码、不需要注册、不需要联网提交——所有数据只存在你自己的浏览器里。

效果预览：`preview-home.png`（首页）、`preview-result.png`（结果页）、`preview-card.png`（导出的分享卡片）。

## 五个维度

| 维度 | 测什么 |
|---|---|
| 心动强度 | 见到、想到 TA 时的第一反应 |
| 投入程度 | 你愿意为这段关系花多少心力 |
| 安全感 | 不确定时你会不会自我消耗（分数越高越不安） |
| 主动程度 | 你是往前走，还是等对方先动 |
| 未来想象 | TA 是否出现在你的长期画面里 |

另有一个**嘴硬指数**：由「更常等对方先动」这道反向计分题，加上主动程度综合算出——嘴上说不在意、身体很诚实的那种。

## 十二种场景

- **还没确定**：日常相处 / 校园暗恋 / 朋友越界 / 网络心动
- **已经在一起**：刚在一起 / 异地 / 校园恋爱 / 长期关系
- **已经分开**：刚分开 / 还在联系 / 断不干净 / 想复合

同一份答案，在不同场景下会给出不同的解读和行动建议。

## 技术说明

- 纯静态前端：index.html + styles.css + js/data.js + js/app.js，零依赖、零构建、零后端
- 数据全部走浏览器 localStorage，不采集、不上传
- 雷达图用原生 SVG 绘制（带生长动画），分数环用 stroke-dashoffset 动画
- 分享卡片用 Canvas 现场绘制并导出 PNG
- 移动端优先，桌面端居中显示，支持安全区域与深色模式

## 本地运行

因为用了 ES Module，需要起一个静态服务（不能直接双击打开）：

```bash
python -m http.server 8000
```

然后打开 http://127.0.0.1:8000 。或用任意静态托管（GitHub Pages / Netlify / Vercel 均可）。
